- **New internal report format**

  The main change in this release: separate files for each signal, keeping
  original EDF samples and their scale. This reduces work when building and
  displaying reports, and lets new therapy data extend an existing report.

- **Configurable report charts**

  Choose from all available signals, including target ventilation and
  trigger/cycle events. Selection, order, and collapsed state are saved on
  AirCANnect and shared across browsers.

### Fixes and improvements

- **Report preparation:** completed intervals are added during therapy; after
  therapy, the ended night's report is prepared before EDF sync starts.
- **Report charts:** actual waveforms are shown at wider zoom levels,
  including flow at around 30 minutes. Event markers can be hidden separately
  for each chart, with that choice remembered in the browser.
- **Report loading:** better reuse of downloaded data after a page reload,
  fewer requests when switching nights.
- **Reports during recording:** more room for open files prevents report
  reads from exhausting the SD file limit alongside active EDF recording.
- **SleepHQ:** requests and uploads now use the platform HTTP client instead
  of a custom response parser.
- **OTA:** cancelling a URL download stops the transfer; increased IPC stack
  space addresses a crash seen during flash operations.
- **Oximetry:** corrected SpO2 and pulse decoding for Nonin's proprietary
  measurement packets.
- **Telemetry:** fixed losing a signal when a consumer added it while another
  consumer already requested it, then that other consumer disconnected.
- **WebUI:** fixed repeated SSE updates involving disconnected chart requests.
  Ready responses no longer wait for the next TCP poll.
- **LCD and audio:** display status refreshes independently of WebUI updates,
  and disabling sound no longer races with tone playback.
- **Crash logs:** older dumps are no longer labelled with details from a
  newer crash.
