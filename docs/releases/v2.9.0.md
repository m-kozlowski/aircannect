#### Oximetry

Oximetry now reaches SleepHQ.
SleepHQ ignores SpO2 and pulse stored in CPAP EDF files, so AirCANnect
uploads them separately, in a format SleepHQ imports and charts.

Oximetry data is recorded whenever the oximeter is connected, not only
during CPAP therapy. Every recording is saved as a CSV file and included
in the night report, with movement and perfusion index when the oximeter
provides them.

An O2Ring or Checkme O2 Max can record overnight on its own.
AirCANnect downloads the recording later over Bluetooth and adds it
to the night report.

#### Scheduled actions

Schedule actions for a set time on selected days or repeat them at a fixed
interval. For example, warm up the humidifier before bed on weekdays or
change the display page every 15 seconds.

#### Other improvements

- Night reports build and load faster.
- Report charts are easier to use on phones, with touch controls for zooming
  and moving through the night.
- The project website now offers a browser-based USB installer.
