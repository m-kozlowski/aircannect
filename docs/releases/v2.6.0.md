#### USB Mass Storage

Access the SD card from a computer as a writable USB drive on supported SDMMC boards. 

#### 90 W PSU identification

Optional 90 W power-supply identification over CAN for compatibility with AirCurve firmware.
Intended for suitably rated power supplies that do not provide their own CAN identification;
disabled by default.

#### Report improvements

- More reliable updates of nights combining local recordings and device
  history, preserving previously saved sessions.
- Fewer unnecessary rebuild attempts when no new data is available.
- Automatic cleanup of obsolete report versions to reclaim SD space.
