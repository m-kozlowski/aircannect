### Important fixes

- **Therapy statistics**

  AHI, apnea, hypopnea, and RERA indexes now use the correct scale. The update
  also corrects inspiratory time, spontaneous trigger and cycle percentages,
  and the respiratory rate and ventilation fields in one-minute trend data.

- **Post-therapy reports**

  AirCANnect refreshes the completed night immediately after therapy instead
  of rescanning the full report history. Very short sessions that never begin
  recording no longer produce incomplete STR records.

- **Air11 BLE pairing**

  Pairing continues after a temporary WebUI connection loss in SoftAP mode, so
  the passkey prompt can still appear when the phone reconnects.

### Repairing STR records from 2.2.0

New records are written correctly after updating. Existing STR records are not
changed automatically. They can be refreshed from the Air11 Summary history
through the management console:

```text
edf str refresh YYYYMMDD [YYYYMMDD]
```

With one date, the command refreshes a single night. With two dates, it uses an
inclusive range. It updates Summary-derived statistics in existing STR records
without changing session timing, settings, or mask events.

To rebuild a report for a repaired night immediately, run:

```text
report rebuild YYYYMMDD
```
