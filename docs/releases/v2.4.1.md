### Fixes and improvements

- **CAN reception:** routine status updates no longer scan for the largest
  free memory blocks, reducing interrupt blocking that can cause lost frames.
- **CAN service transfers:** normal RPC traffic stays paused throughout a
  service connection, including reads started while AirSense is already in
  service mode.
- **Post-therapy reports:** fixed automatic preparation stalling when the
  report catalog grew too large. Source details are now stored separately for
  each night; existing catalogs are converted automatically.
- **Report zoom:** selecting less than a minute now zooms in, with a
  ten-second minimum view.
- **AirSense BLE:** disconnect requests from the AirSense myAir App menu are
  now honored without forgetting pairing or immediately reconnecting. A
  **Connect** button on the dashboard resumes the connection.
- **BLE logging:** repeated failed connection attempts no longer produce a
  disconnect message on every retry.
- **Crash diagnostics:** fixed the panic callback so retained crash details
  are captured before the device restarts.

### Optional crash dump storage

Older installations without a core dump partition can now add one from the
management console on supported flash layouts:

- `crash partition` inspects the layout without changing flash.
- `crash partition create` adds the missing partition and restarts AirCANnect
  on success. Completion or failure is reported in the console.

This is a manual operation, never part of a normal firmware update.
