AirCANnect 2.2 adds configurable local controls, more LCD display pages,
expanded nightly statistics, and improved oximeter discovery.

### Features

- **Configurable buttons**

  Short and long presses can be assigned to local actions from WebUI, CLI, or
  configuration. The input framework supports different boards and button
  layouts without tying actions to the display.

- **More useful display pages**

  Optional displays can show the latest night, 30-day statistics, and live
  therapy details. Pages adapt to the data available in the current therapy
  mode. Startup orientation and automatic rotation are configurable.

- **Expanded therapy reports**

  Reports add RDI, nightly median and 95th-percentile metrics, average leak,
  and labeled respiratory event markers directly on signal charts.

- **Passive oximeter discovery**

  Remembered BLE oximeters are observed without periodic active scans.
  Charging Viatom sensors are skipped with per-device backoff, leaving other
  remembered sensors available for use.

### Fixes

- **Night summaries:** STR files use higher precision values from the Summary
  spool instead of rounded RPC Get reads.
- **Historical reports:** nights outside the device's retained Summary history
  no longer trigger repeated spool requests when existing report data is
  already available.
- **Waveshare hardware:** the board remains powered from its battery, and its
  firmware target is included in normal release builds.
