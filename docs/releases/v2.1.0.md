AirCANnect 2.1 adds BLE connectivity, a ready-to-use display board, and richer
therapy reports.

## At a glance

- **Air11 over BLE**

  Pair an AirSense 11 or AirCurve 11 without a physical CAN connection. Device
  status, clinical settings, EDF capture, reports, and supported firmware
  updates use the selected connection.

- **Waveshare target**

  A solder-free setup with onboard microSD, a local status display, an action
  button, and movement wake and rotation.

- **Richer reports**

  Snore, tidal volume, optional SpO2 and pulse, remembered chart layout, direct
  navigation to the latest night, and faster loading.

- **Setup wizard**

  Guided configuration of Wi-Fi, the AirSense or AirCurve connection, time,
  access credentials, SMB, and SleepHQ.

- **Initial images**

  Complete `-initial.bin` images for first-time installation are included in
  release assets.

## Important fixes

- **BLE:** sessions recover cleanly after link interruptions, and background
  oximeter discovery no longer crowds the AirSense or AirCurve connection.
- **Reports:** missing optional EDF files and unavailable historical device
  data no longer prevent otherwise valid nights from appearing.
- **CAN:** a physically absent therapy device is treated as unavailable instead
  of causing repeated controller recovery.
