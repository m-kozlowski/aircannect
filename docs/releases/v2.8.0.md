#### WebUI languages

The interface is now available in English and Polish. Follow your browser's
language or choose one in Config. The translation system supports adding
more languages, and community translations are welcome.

#### Selected-session statistics

Reports can now show statistics for just the sessions you select, making
it easier to compare separate sessions within the same night. Full-night
statistics remain the default.

#### Other improvements

- Choose a default mask for automatic post-therapy SleepHQ uploads.
- See the current therapy duration beside the Dashboard therapy badge.
- Clearer warnings for low SD space and recording errors, with improved
  recovery after SD write failures.
- Report fixes for sessions crossing noon and reduced memory use,
  particularly on devices with 2 MB PSRAM.
- Fixed communication failures with SHQO2Pro oximeters.
