#### Settings backups

Back up AirCANnect configuration from Config and AirSense 11 therapy
settings from Clinical. Each backup is saved on the SD card with its date,
and older backups are kept. Before restoring, AirCANnect shows what will
change and which values it will skip. 

#### Humidifier warm-up

Start or stop humidifier warm-up from the Dashboard while the AirSense 11
is in standby. The Dashboard shows the current warm-up state. Requires
stock firmware 8.8.0 or newer or airbreak.
